# mysport
My Sport is an AI-powered fitness platform by OwnPace Network, offering personalized sports plans, progress tracking, daily check-ins, and AI-powered fitness guidance.

Blockchain Integration

My Sport by OwnPace Network is designed to integrate with the BNB Chain ecosystem.

The platform supports Web3 wallet connectivity and aims to provide users with a seamless experience within the BNB Chain ecosystem.

Supported Network:

BNB Smart Chain (BSC)
